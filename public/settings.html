إعدادات مفاتيح API

قم بإدخال مفاتيح API الخاصة بك لتفعيل الأدوات. جميع المفاتيح تُحفظ محلياً في متصفحك بشكل آمن.

يستخدم لـ: الدردشة، توليد النصوص، توليد الصور، تحويل الصوت إلى نص، النص إلى صوت
⚠️ قيد التطوير - سيتم دعمه قريباً
يستخدم لـ: الدردشة المتقدمة (بديل لـ OpenAI)
🔒 ملاحظة أمنية مهمة:
مفاتيح API الخاصة بك تُحفظ فقط في متصفحك (Local Storage) ولا يتم تخزينها على خوادمنا.
تأكد من عدم مشاركة مفاتيحك مع أي شخص. يمكنك أيضاً إضافة مفاتيح افتراضية في ملف .env على الخادم.
📌 كيفية الحصول على مفاتيح API:
• OpenAI: https://platform.openai.com/api-keys
• DeepSeek: https://platform.deepseek.com/api_keys
