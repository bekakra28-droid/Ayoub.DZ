# 🚀 منصة يعقوب للذكاء الاصطناعي

[![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)](https://github.com/yaqoub/ai-platform)
[![Node.js](https://img.shields.io/badge/Node.js-18.x-green.svg)](https://nodejs.org)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

منصة ويب احترافية متكاملة لأدوات الذكاء الاصطناعي، تشمل الدردشة الذكية، توليد النصوص والصور والفيديو، تحويل الصوت إلى نص والعكس، مع دعم كامل للغة العربية.

## ✨ المميزات

- 💬 **دردشة ذكية** مع AI (GPT-3.5/GPT-4)
- 📝 **توليد وتحسين النصوص** (كتابة، تلخيص، ترجمة)
- 🎨 **توليد صور** من النص (DALL-E)
- 🎥 **توليد فيديوهات** (قيد التطوير)
- 🎙️ **تحويل الصوت إلى نص** (Whisper)
- 🔊 **تحويل النص إلى صوت** (TTS)
- 💻 **مساعد أكواد برمجية**
- 🌙 **وضع داكن/فاتح** مع حفظ التفضيل
- 📱 **تصميم متجاوب** بالكامل (RTL)
- 🔐 **حفظ آمن لمفاتيح API** محلياً
- 💾 **حفظ المحادثات والصور** تلقائياً

## 📋 المتطلبات الأساسية

- Node.js (الإصدار 14 أو أحدث)
- npm أو yarn
- متصفح حديث (Chrome, Firefox, Safari, Edge)
- مفاتيح API من الخدمات المطلوبة
